# CS 370 Pirate Intelligent Agent Reflection

## 1. What starter code were you given?

I was given starter code that established the maze environment, represented the pirate and treasure, and controlled the available movements within the maze. The starter code also included supporting classes for storing experiences, managing game states, and building the neural network model. This provided the basic structure needed to train and test the intelligent agent.

## 2. What code did you create yourself?

I completed the deep Q-learning training code that taught the pirate agent how to navigate the maze and reach the treasure. My code allowed the agent to select actions, receive rewards, store experiences, and learn from previous attempts through experience replay. I also worked with exploration and exploitation, the discount factor, epochs, and neural-network training. The completed training process allowed the pirate to improve its decisions over time and eventually find an efficient path to the treasure.

## 3. What do computer scientists do, and why does their work matter?

Computer scientists use technology, mathematics, and logical thinking to solve problems. They design algorithms, develop software, analyze information, and create systems that can improve how people complete tasks. Their work matters because computer systems are used in nearly every industry, including healthcare, transportation, finance, education, aviation, and national defense. Computer scientists help make these systems more efficient, dependable, secure, and accessible.

## 4. How do you approach problems as a computer scientist?

I approach a problem by first identifying the desired outcome and dividing the larger problem into smaller, manageable parts. I review the requirements, examine the available code or information, and determine what must be added or corrected. I then implement and test one part at a time. When an error occurs, I examine the error message, review the relevant code, and make focused changes instead of changing everything at once. This project showed me that testing, patience, and step-by-step problem-solving are essential parts of computer science.

## 5. What ethical responsibilities do you have to users and organizations?

My ethical responsibilities include protecting user privacy, securing sensitive information, testing software carefully, and being honest about a system’s capabilities and limitations. I must also consider whether an algorithm could produce biased, unsafe, or unfair results. For an organization, I have a responsibility to follow security policies, protect its data, document my work, and avoid releasing software that could harm its users or reputation. Artificial intelligence should be developed with human oversight and should support users rather than deceive, manipulate, or discriminate against them.
